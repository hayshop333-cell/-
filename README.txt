CRYPTOLAB — demo website
========================

Բացիր index.html-ը ժամանակակից դիտարկչում։ Կայքը աշխատում է առանց սերվերի և արտաքին գրադարանների։

Ներառված է
- Հեռախոսների համար հարմար responsive դիզայն
- Մեծ ավտոմատ սլայդշոու
- Մորզե (լատինատառ և կայքի հայերեն ընդլայնում), UTF-8 Binary/Base64, հայերեն և լատինատառ Caesar, Atbash
- AES-256-GCM գաղտնագրում՝ PBKDF2-ով
- Ապակոդավորում/վերծանում
- Ստացված արդյունքը մեկ սեղմումով մուտքի դաշտ տեղափոխելու հնարավորություն՝ կրկնակի վերծանման համար
- Միջազգային և հայերեն Մորզեի, ինչպես նաև ASCII/Binary աղյուսակներ
- Միայն արդյունքի տեքստի PDF արտահանում՝ դիտարկչի Print → Save as PDF գործառույթով
- Տեղային ցուցադրական վիճակագրություն և ադմին էջ

Կարևոր անվտանգության սահմանափակումներ
1. Սա նախատիպ է, ոչ production-ready կայք։
2. Ադմինի ցուցադրական գաղտնաբառը `morze` է և գրված է frontend կոդում, ուստի իրական պաշտպանություն չէ։
3. Վիճակագրությունը localStorage-ում է և տեսանելի է միայն նույն դիտարկչում/սարքում։
   Համընդհանուր վիճակագրության համար անհրաժեշտ է backend և ադմինի սերվերային authentication։
4. Հաղորդագրությունների տեքստը չի ուղարկվում սերվեր և չի պահպանվում հավելվածի կողմից։
   Սակայն օգտատիրոջ սարքը, browser extensions-ը կամ վնասակար ծրագրերը կարող են հասանելիություն ունենալ։
5. Հրապարակելուց առաջ անհրաժեշտ է անվտանգության անկախ ստուգում, HTTPS, CSP և սերվերային ադմին մուտք։
6. Հայերեն Մորզեի կոդերը կայքի հետադարձելի ընդլայնումն են, ոչ թե միջազգային ստանդարտ։ Atbash-ը հայերեն նիշերը պահպանում է անփոփոխ։
7. Base64, Morse, Caesar և Atbash-ը գաղտնիություն չեն ապահովում։ Գաղտնի տվյալների համար օգտագործել AES-GCM։

PDF: սեղմել «Արտահանել PDF», ապա տպման պատուհանում ընտրել Save as PDF։
